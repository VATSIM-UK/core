VATSIM UK · Events pages design preview v4 — read-only concept Direction A

Changes

  • Event dates on the detail page now use the admin format — DD. MM. YYYY (App\Support\DateFormat::DATE), matching the admin panel.
  • Detail heading moved below the cover. The cover is now a plain image strip; the event name sits in the navy bar underneath, matching the airport/dashboard/bookings header convention (headings are never overlaid on banners).
  • Organisers now show the CID too — e.g. Alex S. (1234567) (bookings-calendar name format + CID).
  • Bookable events link to the calendar. When an event is not rostered, a "Book a position" action appears and the Booking row reads Open; rostered events show no link. See the rostered vs open comparison on page 2b.

London Luton Live

★ Rostered
A full evening covering the London TMA and its busiest airports. 18. 10. 2026 18:00 – 22:00z · 4 hours
About this event

Join us for a full evening in the London TMA as we staff Luton, Heathrow and Gatwick together. Whether you're departing the region or working the radar, it's set to be one of our busiest events of the autumn.

What to expect

  • Continuous ATC coverage from 18:00z to 22:00z.
  • Rostered positions reserved for pre-booked controllers until 17:45z.
  • Pilot briefing and route suggestions published in the event thread.

Pilots are asked to file IFR and expect high traffic volumes on the ground. Controllers should review the position briefing before logging on.
